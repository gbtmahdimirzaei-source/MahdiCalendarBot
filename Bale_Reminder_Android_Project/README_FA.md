# یادآور کاری بله — اپلیکیشن اندروید (نسخه ۱.۰)

برنامه اندروید مستقل از افزونه Chrome، با رابط کاربری فارسی و راست‌به‌چپ، تاریخ شمسی و اتصال به API رسمی بازوی بله.

## قابلیت‌ها
- ثبت، ویرایش و حذف برنامه‌های کاری با عنوان، توضیحات، تاریخ شمسی و ساعت محلی گوشی
- یادآوری سر موعد یا ۵، ۱۵، ۳۰ و ۶۰ دقیقه قبل
- تکرار روزانه، هفتگی یا یک‌باره
- اعلان محلی گوشی و ارسال متن یادآوری به گفتگوی شخصی شما در بله
- دریافت خودکار Chat ID عددی از پیام‌های اخیر بازو و انتخاب گفتگوی صحیح
- ارسال پیام آزمایشی برای بررسی اتصال
- زمان‌بندی مجدد پس از روشن‌شدن دوباره گوشی یا تغییر ساعت/منطقه زمانی
- نگهداری برنامه‌ها و توکن صرفاً در فضای خصوصی اپلیکیشن روی گوشی (بدون پشتیبان‌گیری ابری)

## ساخت APK با Android Studio

> فایل پروژه **کد منبع** است؛ APK از پیش کامپایل‌شده داخل ZIP نیست. چون محیط تولید فاقد Android SDK است، نصب، اجرا و ارسال واقعی به حساب بله در این محیط آزمایش نشده‌اند.

1. نرم‌افزار **Android Studio** را نصب کنید؛ JDK 17 یا نسخه سازگار داشته باشید.
2. پوشه `Bale_Reminder_Android_Project` را از ZIP بیرون بیاورید.
3. در Android Studio گزینه **Open** را بزنید و همان پوشه پروژه را انتخاب کنید.
4. اتصال اینترنت داشته باشید تا Gradle 8.9، Android Gradle Plugin 8.7.3 و Android SDK Platform 35 تهیه شوند. اگر Gradle Distribution لازم بود، در Settings > Build, Execution, Deployment > Build Tools > Gradle، نسخه Gradle 8.9 و Gradle JDK 17 را انتخاب کنید.
5. به منوی **Build > Build Bundle(s) / APK(s) > Build APK(s)** بروید.
6. فایل معمولاً در `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.
7. APK تولیدی را روی گوشی اندرویدی نصب کنید. نسخه پشتیبانی‌شده: Android 8.0 (API 26) و بالاتر.

**روش جایگزین ساخت:** فایل `.github/workflows/build-apk.yml` آماده است. با قرار دادن پروژه در مخزن GitHub و اجرای workflow «Build Android APK»، فایل `app-debug.apk` را از بخش Artifacts دریافت می‌کنید. توکن بله را هرگز در مخزن قرار ندهید؛ برنامه پس از نصب توکن را می‌گیرد.

## راه‌اندازی ربات بله
1. در برنامه بله یک **بازوی اختصاصی برای یادآوری کاری** با `@botfather` بسازید و توکن اختصاصی دریافت کنید. توصیه می‌شود از بازوی سیگنال بورس جدا باشد.
2. در گفتگوی خصوصی بازوی جدید پیام `/start` ارسال کنید.
3. اپ را باز کنید > **تنظیمات بله** > «توکن بازو».
4. روی «پیدا کردن شناسه از پیام‌های بازو» بزنید. گفتگو را انتخاب کنید تا Chat ID **عددی** وارد شود. `@username` شناسه گفتگو نیست.
5. «ذخیره اتصال» و سپس «ارسال پیام آزمایشی» را بزنید.
6. در زبانه «برنامه‌های من»، برنامه جدید ثبت کنید.

اگر Chat ID پیدا نشد: یک پیام جدید «سلام» در گفتگوی بازو بفرستید و در ۲۴ ساعت بعد مجدداً جستجو کنید. getUpdates با وب‌هوک فعال یا برنامه دیگری که همان صف پیام‌ها را می‌خواند می‌تواند تداخل داشته باشد. از بازوی اختصاصی استفاده کنید.

## مجوزها و محدودیت‌های واقعی
- **اینترنت** برای دسترسی به `https://tapi.bale.ai` ضروری است.
- در Android 13+ مجوز اعلان‌ها برای **اعلان محلی** باید تأیید شود؛ رد کردن آن الزاماً ارسال پیام بله را متوقف نمی‌کند.
- در Android 12+ ممکن است لازم باشد در تنظیمات، مجوز **Alarms & reminders** / «زمان‌بندی دقیق» را فعال کنید. در غیر این صورت، برنامه از آلارم غیردقیق استفاده می‌کند.
- برنامه به مرورگر و رایانه وابسته نیست؛ اما **گوشی باید روشن باشد** و برای ارسال به بله اینترنت و امکان اجرای کار پس‌زمینه داشته باشد. بهینه‌سازی شدید باتری، Doze، دسترس‌نبودن شبکه یا محدودیت سازنده گوشی می‌تواند اعلان یا ارسال را به تأخیر بیندازد.
- هنگام خاموش بودن گوشی یا نداشتن اینترنت، ارسال سر وقت تضمین نمی‌شود. برنامه تلاش می‌کند رویدادهای تا ۲۴ ساعت پیش را جبران کند و رویدادهای قدیمی‌تر را از دست‌رفته علامت می‌زند یا تکرار بعدی را زمان‌بندی می‌کند.
- اگر اتصال به بله قطع باشد، JobScheduler با سیاست تلاش مجدد اندروید برای ارسال اقدام می‌کند. ممکن است در شرایط استثنایی و در قطع برنامه میان پاسخ موفق سرور و ثبت موفقیت، **پیام تکراری** دریافت شود.
- توکن در SharedPreferences خصوصی اندروید ذخیره می‌شود؛ این پروژه **رمزگذاری اختصاصی در سطح برنامه ندارد**. روی گوشی ناامن/روت‌شده یا مشترک استفاده نکنید. پشتیبان‌گیری خودکار برنامه غیرفعال است.
- این نسخه با Google Calendar همگام نمی‌شود، سرور ابری ندارد، یادآوری را مستقیماً از روی گوشی می‌فرستد.

## مشخصات فنی
- زبان: Java 17 (بدون کتابخانه شخص ثالث در زمان اجرا)
- Native Android SDK, minSdk 26, targetSdk 34, compileSdk 35
- Android AlarmManager + JobScheduler + BootReceiver
- API رسمی: `POST https://tapi.bale.ai/bot<TOKEN>/sendMessage` و `getUpdates`
- تمام تنظیمات و داده‌ها در دستگاه ذخیره می‌شوند؛ کد هیچ توکن پیش‌فرض یا شناسه شخصی ندارد.

## نکته برای توسعه‌دهندگان
این نسخه یک پروژه قابل build است؛ بااین‌حال به علت نبود Android SDK و دستگاه فیزیکی در محیط تولید، تست Build و تست دستگاه اینجا انجام نشده است. قبل از استفاده جدی، روی دستگاه واقعی زمان‌بندی دقیق، آغاز مجدد پس از reboot، قطعی اینترنت و اتصال ربات بله را آزمایش کنید.
